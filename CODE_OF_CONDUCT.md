# Code of Conduct

## Our standard

Easy Print contributors are expected to communicate with respect, assume good intent, welcome constructive feedback, and keep technical disagreement focused on evidence and project outcomes.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, deliberate disruption, publication of private information, and unsafe disclosure of security vulnerabilities.

## Scope

This standard applies to repository activity, Issues, pull requests, discussions, and other spaces used to represent the project.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. The maintainer may edit or remove contributions, restrict participation, or take other proportionate action. Reports will be handled with discretion and without retaliation.
